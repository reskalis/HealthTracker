# HealthTracker

Privacy-first, local-first personal health tracking PWA.

## Privacy
Health records stay on the user's device. This public repository contains application code only—never personal health exports or CSV backups.

## Planned v1
- Morning check-in
- Weight and waist measurements
- Blood pressure and pulse
- Workout logging
- Local/offline storage
- History and simple trends
- CSV import/export and backup
